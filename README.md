# 🎨 Artist Portfolio

A simple and elegant **Artist Portfolio Website** designed to showcase creative photographs and artwork in a clean, modern gallery-style interface.

## ✨ Features

* 🖼️ Beautiful image gallery
* 🎨 Artistic and minimal design
* 📱 Responsive layout for mobile, tablet, and desktop
* 🔍 Individual artwork/photo viewing
* 📝 Titles and short descriptions for each artwork
* ✨ Smooth and subtle animations
* 📧 Simple contact section
* ⚡ Fast and easy-to-navigate interface

## 🖌️ Portfolio Sections

* **Home** – Introduction and featured artwork
* **My Work** – Collection of uploaded photographs
* **About** – Short introduction about the artist
* **Contact** – Contact information

## 🎯 Purpose

The purpose of this portfolio is to provide a simple digital space where an artist can **showcase their creativity, photographs, and artistic work** in an attractive and professional way.

## 🛠️ Technologies

* HTML
* CSS
* JavaScript
* Responsive Web Design

## 🚀 Getting Started

1. Clone or download the project.
2. Add your photographs to the `images` folder.
3. Update the artwork titles and descriptions.
4. Open `index.html` in a browser.

## 🎨 Design Philosophy

The portfolio follows a **minimal contemporary art-gallery style**, keeping the photographs as the primary focus while using clean typography, whitespace, and subtle animations to enhance the viewing experience.
